# Link Genie

Build a cool-looking URL shortener web app. Include a polished landing page and authenticated-style dashboard experience with link creation, custom aliases, copy/share actions, QR code generation, click analytics, and link management. Use a bold, modern visual direction and make it responsive. Enable the backend needed for persisted links and analytics.
